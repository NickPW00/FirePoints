# data/processed — files read by the app

> **AI-assisted data.** Every file in this folder was generated by the scripts in [`pipeline/`](../../pipeline/), which were written with the help of Claude (Anthropic) and reviewed by the team. The input data are NASA FIRMS active-fire detections (MODIS C6.1 and VIIRS S-NPP 375 m) and IBGE boundaries. No value here was typed or invented by an AI: every number comes from running the pipeline on those inputs. Details in [`docs/AI_USE.md`](../../docs/AI_USE.md).

| File | Written by | Content |
|---|---|---|
| `grade_mensal.parquet` | `01_processar_focos.py` | Raw detections per sensor × 0.1° grid cell × month |
| `serie_harmonizada.parquet` | `03_harmonizar.py` | Harmonized detections (VIIRS scale) per grid cell × month, with status |
| `fatores_bioma_mes.csv` | `03_harmonizar.py` | Factor k = S-NPP ÷ MODIS per biome and month, calibrated on Feb 2012 – Dec 2019 |
| `validacao_harmonizacao.csv` | `03_harmonizar.py` | Leave-one-year-out validation error per biome |
| `calendario.parquet` | `04_calendario.py` | Region × year × month: detections, historical mean, anomaly and color classes |
| `quadradinhos.parquet` | `04_calendario.py` | Each grid cell with its biome and state |
| `focos/ano=<year>/focos_<year>_<sensor>.parquet` | `05_exportar_focos.py` | Individual detections (raw, not harmonized), split by year and sensor |

Full column descriptions: [`docs/contrato-dados.md`](../../docs/contrato-dados.md).

## Glossary of Portuguese names

Column and file names are in Portuguese because the pipeline was written in Portuguese. The app translates all of them in its interface and in the CSV downloads.

| Portuguese | English |
|---|---|
| `focos` | fire detections (hotspots) |
| `quadradinho(s)` | grid cell(s) of 0.1° |
| `ano`, `mes` | year, month |
| `bioma` | biome |
| `estado`, `estado_nome` | state code, state name |
| `regiao`, `regiao_tipo`, `regiao_nome` | region, region type, region name |
| `confianca` | confidence |
| `data` | date (local, America/Sao_Paulo) |
| `dia_noite` | day/night flag |
| `media_mes` | historical mean of the month (2003–2025) |
| `anomalia_pct` | anomaly (%) versus that mean |
| `faixa_anomalia`, `faixa_intensidade` | anomaly class (1–5), intensity class (0–5) |
| `status`: `observado`, `estimado`, `parcial` | observed (VIIRS), estimated (MODIS × k), partial (Terra only) |
| `fatores_bioma_mes` | factors per biome and month |
| `validacao_harmonizacao` | harmonization validation |
| `serie_harmonizada` | harmonized series |
| `calendario` | calendar |
